## Visual Assets

The visual assets in the game are self-drawn by the group.

This includes:

- Human sprites: `src/main/resources/assets/humans/*.png`
- Phantom sprites and glitch variants: `src/main/resources/assets/ghosts/*.png`
- Floor tiles: `src/main/resources/assets/floors/*.png`
- Ability sprite: `src/main/resources/assets/abilities/ability.png`
- Map and documentation images: `src/main/resources/assets/map_concept.png`,
  `documentations/images/*.png`, `outreach/screenshot.png`

## Video

`outreach/video.mp4` was created by the group for the project trailer/gameplay
submission. It should only contain the self-drawn game visuals and the sound
effects listed above.
