# PhantomHunt GitHub Pages

This folder is a static GitHub Pages site for the personal HerRei/PhantomHunt repository.

To publish it:

1. Open the repository on GitHub.
2. Go to Settings -> Pages.
3. Set the source to "Deploy from a branch".
4. Select the main branch and the `/docs` folder.
5. Save.

No build step is required. The site uses only HTML, CSS, JavaScript, and copied static assets.
